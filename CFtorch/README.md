# CrystalFormer (PyTorch Version)

This repository provides a PyTorch reimplementation of [CrystalFormer](https://github.com/deepmodeling/CrystalFormer), originally written in JAX. The current codebase is adapted from version `v0.1` of the original CrystalFormer project.

## 🔄 Origin and Modification

- **Original project**: [https://github.com/deepmodeling/CrystalFormer](https://github.com/deepmodeling/CrystalFormer)
- **Original version**: `v0.1` (JAX-based implementation)
- **This version**: Rewritten in **PyTorch** for improved compatibility, ease of use, and integration with other PyTorch-based materials discovery frameworks.
